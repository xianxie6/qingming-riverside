# 从长卷到街市

## 为什么做

《清明上河图》最迷人的地方，不只是繁盛的街景，而是它让观看者沿着河岸缓慢移动：从郊野到市井，从水路到桥头，再到城门。画卷本身已经带有一种接近漫游的时间感。

这个项目从一个简单的问题开始：如果不把古画当成一张静止图片，而把它理解为一段可以进入、停留和继续前行的空间，会发生什么？

因此，它不是要重制或替代原画，而是尝试把“移步换景”的观看方式转成网页上的互动体验。使用者可以沿河行走、乘船、遇见街坊、在桥边参与过船，也可以在夜景和时雨中重新观看同一条街。

## 如何把古画转成可互动街市

传统长卷没有固定的单一观看中心。它通过横向展开、人物和货物的细部、桥梁与河流的转换，让观看者自己决定停在何处。项目保留了这三个原则：

- **横向漫游**：街市按长卷的方向延展，使用者不是在多个独立页面间跳转，而是沿同一条汴河移动。
- **日常叙事**：重点不是英雄事件，而是饮茶、送货、摆摊、织作、撑篙、候船等细小活动。它们持续发生，形成街市的呼吸。
- **水陆相接**：河面、码头、渡船和虹桥不是背景装饰，而是把人群、货物与观看路径连接起来的结构。

在此基础上，项目用 Canvas 与 WebGL 组合绘制静态画卷和动态图层：建筑与纸本质感保持稳定，人物、船、水、雨、灯火和声音在其上缓慢变化。这样既保留长卷的平面观看方式，也让画面具备可探索的时间。

## 参考了什么

视觉和叙事参考来自《清明上河图》所呈现的宋代城市生活，以及传统工笔和界画中细密线条、低饱和设色、横向构图、留白与节奏的处理。

项目参考的是这些观看和绘画语言：沿河展开的空间关系、桥与城门作为转场、密集生活细节与安静留白并置、以及人群和器物共同构成的市井秩序。

它没有使用《清明上河图》的原画扫描、裁切或人物素材，也不试图复刻其中的具体建筑或人物。项目中的长卷背景、扩展街区、人物图层、夜景、降雨和互动事件均为原创生成插画与程序化再创作。

## 原创再创作的部分

- **空间**：水磨作坊、沿河茶市、虹桥、城门货市组成一条可连续漫游的原创街市。
- **人物**：人物的服色、动作、路线和日常工作被拆成独立图层，以便在画卷中持续发生。
- **互动**：行走、候船、乘船、虹桥过船、牵引绳索、夜景与清明时雨，都是为网页体验重新设计的事件。
- **时间**：同一条河岸会进入白天、夜晚和雨中；灯火、水纹、伞面、风和声音改变观看气氛，而非追求写实模拟。

## 希望留下什么

这个项目希望把“看一幅画”变成一次可以自己决定节奏的游历。你可以只停在水磨边看落水，也可以从茶市走到桥头，再乘船离开；也可以在夜里和雨里回到同一处，发现街景改变后仍保留的生活细节。

长卷的价值并不只在于一眼看尽，而在于愿意慢慢展开。这个网页想保留的，就是这种慢慢进入画中的过程。
