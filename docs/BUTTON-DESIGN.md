# 项目按钮约定

纯图标按钮仅保留单线边框，透明底色，不使用双线、回纹或投影；新增纯图标按钮使用 icon-button 类。上菜按钮只显示“上菜”，不带箭头。

用户指定：所有可见操作按钮统一沿用备餐确认按钮的暖金双线、深褐底色、回纹角饰。只有用户另行要求单独设计时例外。

共用样式为 buttons.css，在页面业务样式之后加载。新增页面也应加载；新增可见按钮默认使用原生 button，无需复制单页皮肤。紧凑文字与箭头间距为 7px。保留各操作的位置、尺寸与无障碍名称。

画面透明点击区域 .scene-action、地图位置圆点 .district-stop 属于空间交互标记，保留其点击范围与几何形状，不覆盖成矩形按钮。

画卷页（body.scroll-page）例外：首页景点入口、透明热点、底部控制栏及原有画卷操作按钮保持各自原样，不套用共用皮肤。该页仅 #midautumnEntry 和 #midautumnBack 使用暖金按钮样式。
