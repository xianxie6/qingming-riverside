# 古城寻趣 · 地形画卷探索

2026-10-07，依据《古城寻趣-交互画卷探索需求文档》V1.0 实现。保留原有街市体验，首页新增「古城寻趣」入口，独立页面为 `explore.html`。沿用原生 ES modules、CSS 与现有静态构建。

## 运行

```sh
npm run build
python3 -m http.server 8766 --directory dist
```

浏览器打开 http://localhost:8766/explore.html 。不能使用 file:// 直接打开。首页也可以进入。

电脑拖动移动、滚轮缩放、点击寻找；手机单指移动、双指缩放。缩放按钮和「全图」不修改进度。任务可任意顺序发现；先点任务只显示线索，不移动镜头。已发现任务可以定位并重读。提示第一次给文字，之后显示约 3 秒的大范围光圈，不会自动完成。

键盘 Tab 访问控件；聚焦画卷后，方向键移动，＋ / − 缩放，Home 查看全图；Escape 关闭内容弹层。「列表导览」逐项阅读，不累计寻物进度。声音默认为关，开启后使用浏览器实时合成短音。

## 配置与结构

- `src/explore-data.js`：12 项目标、难度、文案、缩略图、归一化矩形热点、焦点与提示范围；3 个彩蛋。
- `src/explore-geometry.js`：矩形/多边形命中、最小区域优先、存档校验。
- `src/explore.js`：同一 DOM 变换下的图片与 SVG 效果、拖动惯性、双指缩放、任务、计时、弹层及存档。
- `styles/explore.css`：纸色面板、收集手帖、移动端底部抽屉、减少动态效果。
- `tests/explore.test.cjs`：热点重叠、各目标可命中、无效旧存档过滤。

存档键 `ancient-city-explore-v1`，版本 `topographic-1`。保存目标、彩蛋、提示次数、有效时长、归一化视口与声音偏好。隐藏页面和内容弹层期间暂停计时；存储失败降级为当前页内存。重新探索须二次确认。

本机地址加 `?debug=1` 可显示热点、ID、点击坐标，R 打开重置确认。非 localhost / 127.0.0.1 / ::1 地址不启用此模式。

## 素材清单与调整

| 文件 | 来源 / 用途 |
|---|---|
| `art-source/explore-topographic-original.png` | 本对话生成的第二版俯视地形图原始 PNG，保留原稿、不进入发布包 |
| `assets/explore/painting.webp` | 原稿高质量 WebP，运行时底图 |
| `assets/explore/preview.webp` | 640 像素宽轻量加载预览 |
| `assets/explore/{目标ID}.webp` | 从同一底图裁出的 12 张目标局部图 |
| `assets/fonts/sunyang-brush.woff2` | 沿用项目本地标题字体 |
| 彩蛋光圈、水波、发现标记 | SVG 程序绘制，无外部素材 |
| 发现反馈、茶市短音 | Web Audio 合成，无外部录音和网络音频依赖 |

原稿尺寸以文件为准，目前约 2004 × 785。来源为生成插画，不是历史原画或真实地形测绘。文案只描述可见内容，不指认历史人物或年代。

按图片调整：原需求「撑船人」在此底图中不可清楚辨认，改为上游「细长小舟」。茶市、货市分别指定一顶浅色茶棚和一组方形货包，避免整片街区都是答案。桥上行人是桥中部一个小身影，缩放后寻找；与虹桥重叠时较小的人物热点优先。

水车缺少独立透明层和背景补全，依需求降级为局部金色光影，不旋转底图。茶市彩蛋目前为合成短音，并非实录市井叫卖。后续若提升逼真度，可补充水车分层与确认许可的短促市井音效。若要进一步加强人物细节，应提供保持构图一致的高清重绘，重新复核人物热点；不要用无限放大代替清晰素材。

## 实际验证

- `npm run build`：155 个发布文件通过路径与素材白名单检查。
- `npm test`：136 项全部通过，包括新增命中/存档测试与更新后的发布页面夹具。
- 桌面 Chromium：实际逐个点击 12 个目标完成；各目标提示、介绍卡、完成统计可用；重复点击不重复计数；拖动不计为点击；列表导览不累计发现。
- 实测刷新继续探索恢复 12/12；三个彩蛋均可触发并存档；重置回到 0/12；默认静音。
- 390 × 844 移动视口：底部抽屉默认收起、放大、键盘操作、导览可用。
- Chromium CDP 模拟双指触控：缩放生效，松手不触发目标或介绍卡。
- 嵌套导览 Escape 关闭后焦点回到最初的帮助按钮。
- 模拟主图请求失败：展示重新加载入口，恢复网络后重试成功。
- 模拟存储写入异常：出现「本次进度仅在当前页面保留」，主流程可继续。
- 截图位于 `output/playwright/explore-desktop.png`、`explore-mobile.png`、`explore-mobile-guide.png`、`explore-complete.png`。
