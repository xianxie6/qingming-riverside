## 空间主线

从最左往最右：田畴与灌溉 → 农舍与菜园 → 原水磨作坊 → 原茶市、虹桥 → 原城门货栈 → 漕运仓场 → 城郊客舍与柳岸。

密度有起伏：左侧疏朗，中间繁盛，右侧仓场有一处次高潮，最右再舒缓。保持中央茶市和既有城门的视觉地位。

### 左侧：从现有边缘向左展开

1. **接缝段，约新增宽度的 20%**：接续原菜圃、竹篱、桑树和村舍，逐渐减少房屋。岸线与行走路面先平稳延伸，再用低矮草坡和树丛做变化。
2. **菜园村居，约 35%**：高低错落的小块菜畦、豆架、竹篱门、井台、竹筐、农具棚、两三处农舍。院间小径通向沿河主路，生活物件集中在有人使用的位置。
3. **田畴灌溉，约 45%**：更开阔的田块、田埂、小水渠、少量树丛与远处低矮村屋。以一处渠口或简朴跨渠小桥形成辨识点，最左用柳堤和延伸的小路收束。

田地主要放在道路后方，通过重叠和细节疏密表现深度，沿用当前横向立面视角。避免为了展示田块突然变成高空俯视；不把大片田地铺到现有前景河道中。

建议独立人物：浇菜、松土、挑菜入市、井边提水等小组。先做少量有动作目的的人物，再决定是否需要鸡、鸭、牛等动物素材。

### 右侧：从现有货栈向右展开

1. **接缝段，约新增宽度的 20%**：接续货栈屋檐、木料堆与岸边装卸设施；城墙作为后景有节奏地延伸，局部被树和屋顶遮住。
2. **漕运仓场，约 45%**：粮袋、竹篓、仓廒、装卸平台、手推车和系船设施组成新的生活节点。保持沿河通行主路，不用货物堵满人物行走空间。
3. **城郊客舍与柳岸，约 35%**：小型脚店、供行旅歇脚的茶棚、院落与树荫，建筑逐渐稀疏；最右让河道和道路延伸到画外。

当前城门正面朝向观看者，横向路在城门前经过。右移并不等于穿过门洞入城，因此新增内容先按沿墙、沿河的仓场与城郊组织；若以后需要城内主街，应另行设计明确的穿门路线。

建议独立人物：搬货、验货、推车、牵驴歇脚、茶棚小坐。静态建筑和货物留在底图，人物与可动船只单独绘制。

## 画面连续性

- 采用现有淡墨、暖纸色、灰绿与赭色，统一线条细度、屋瓦密度、树冠尺寸和人物比例。
- 以现有路面约 y=477、河岸及水面边界为接缝基准，实际接缝须逐段比对。先保持前景主河道连续，以兼容原有河水与船只活动。
- 接缝放在树丛、竹篱、低墙或缓变地面处，避免切断屋顶、门洞、重要树干与装卸器械。
- 素材以现有相邻边缘作为直接参考；先做整体草案与接缝试片，再分段完成。留重叠区，必要时单独重绘接缝，不能只用透明渐变掩盖透视错误。
- 春季构图先固定，再生成其余季节。四季严格保持道路、桥、建筑和遮挡位置一致；田间作物与人的农事动作需配套变化，冬季减少田间劳作。
- 夜景在村居保留稀疏窗火，在仓场与客舍形成局部暖光，田野整体保持暗与静。

## 实现顺序

1. **构图草案**：输出左右分区草图、接缝放大对照及新旧全卷缩略预览，锁定宽度与视角。
2. **春季无人底图**：完成两侧各片段、接缝和统一色调，检查连续横移时的路面、河岸、屋顶和树木尺度。
3. **街区配置与加载**：将当前固定 west/center/east 的加载与绘制改为可扩展街区表；保留原世界坐标，新增向两侧追加。只加载当前及邻近片段，并为已访问素材设置缓存策略。
4. **通行与人物**：扩展镜头和主角边界，逐段标注站立位置、行走路线、前景遮挡及点击范围；增加田畴与仓场快速定位点。
5. **环境一致性**：补充新街区四季底图、夜景窗灯及天气覆盖。季节切换保证当前画面同时切换，远处按所选季节加载，避免整卷变大后每次切季都等待全部素材。
6. **整卷验证**：桌面与手机从最左走到最右，检查接缝、缩放、定位、快速往返、季节切换失败恢复、夜雨/冬雪、船只范围及原有互动。对比扩展前后的首屏加载和行走流畅度。
