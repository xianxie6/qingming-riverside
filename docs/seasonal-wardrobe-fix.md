# 冬装图集与夏雨服饰修正

`assets/seasons/people-winter-v1.png` 使用内置 image_gen 编辑原始 `assets/people-ink.webp`，1536 × 1024，12 人位置和姿势保持注册；白底经现有轮廓提取后用于人物动画。

提示词规格：仅修改服装；保留 12 人原来的画面位置、尺寸、身份、脸、手脚位置、动作、担子、篮子、杯碗、茶壶与托盘。宋代风格冬季平民服饰：厚实有里交领右衽袍或工作短衣、女子夹褙子与长裙、长裤、布鞋；挑担人、孩童和工匠的手臂、腿脚遮蔽到手腕及鞋口。保留水墨线条与衣褶，不添加现代拉链、羽绒服、清代官服、背景、文字或落雪。原始白底，完整人物，图集布局不变。

## 接入约束

- `Inhabitants.prepareFrames` 共享原有轮廓提取；冬装异步加载，场景与服饰全部就绪后一起切换。
- 冬装整幅人物纹理直接用于渲染，不叠加春装的蒙版、披肩或恢复春装裸露皮肤。脚部接触点从冬装图集重新读取。
- 秋季也使用完整服装图集 `people-autumn-v1.png`，去掉原灰色披肩；画师使用无披肩的 `featured-autumn-v2.png`。春夏恢复原服饰。制作提示词见 [宋式秋装](prompts/song-autumn-wardrobe.md)。
- 夏雨服饰缓存键与晴天相同，只添加现有撑伞动作；降雨、倒影及雨后收伞保留。
- 发布白名单仅增加冬装人物图集，入口范围不扩大。
