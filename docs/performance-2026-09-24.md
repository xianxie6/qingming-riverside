# 2026-09-24 性能优化检查

## 范围

只调整资源编码和烟花内部计算；画面尺寸、粒子数量、配色、轨迹、音频、页面布局及节日时间表不变。街市、孙羊正店的交互逻辑不变。

## 实际优化

- 五张透明 PNG 重新无损压缩，仍使用 PNG，避免浏览器对透明 WebP 的预乘透明度舍入差异。
- 中秋白天天空是不透明图片，使用无损 WebP；六张图片合计减少 1,075,510 字节（约 1.08 MB）。首页直接使用的三张素材减少 335,202 字节。
- 未播放烟花时不生成文字和造型模板；尺寸未变时重用模板。首次播放正常准备，真正调整尺寸时重新生成。
- 烟花拖尾复用已有坐标对象，亮度分组每个粒子每帧只计算一次，预览参数只解析一次。

## 质量验证

- Pillow 解码 RGBA 字节一致；浏览器 Canvas 比较六张素材的每一个通道，完全一致。
- 固定随机种子，在桌面及手机尺寸分别模拟 100 秒，烟花轨迹、颜色、粒子数量、拖尾及节目进度一致。
- 18 个确定性烟花样本帧的浏览器 Canvas 像素一致，包含普通绽放和插播。
- 浏览器回归：活动前烟花模板读取为 0；首次开场读取 4 次；同尺寸暂停 / 恢复不重复读取；换尺寸正确重建；22:00 完成 6 幕后恢复；静音及午夜停止正常，无页面异常。
- `npm test`：103 项通过；`npm run check`：构建及 Cloudflare dry-run 通过。

## 本机运行抽样

使用同一 Chromium、1440 × 900、全新上下文、禁用网络缓存，每个场景运行采样 4 秒。这里只是本机诊断数据，并非真实用户 Core Web Vitals 或所有设备的帧率保证。后台预加载和音频范围请求会影响总传输量，资源收益以上述文件大小和逐像素对比为准。

| 场景 | 脚本耗时 / 4 秒：之前 → 之后 | Canvas 读取次数：之前 → 之后 |
|---|---:|---:|
| 首页 | 17 ms → 16 ms | 32 → 28 |
| 22:00 烟花文字 | 2345 ms → 2023 ms | 36 → 32 |
| 虹桥街市 | 3009 ms → 2612 ms | 41 → 37 |
| 中秋街市 | 2982 ms → 2795 ms | 59 → 55 |
| 孙羊正店 | 162 ms → 166 ms | 33 → 33 |

街市和店铺的运行代码没有为追求数字而更改，采样差异包含系统负载与场景时刻的波动。烟花保留全部粒子、分辨率及光晕。

详细本地采样和比对脚本位于 `output/performance/`（不随网站发布）。
