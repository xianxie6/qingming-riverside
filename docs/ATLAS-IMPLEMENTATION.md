# 长卷交互与素材交接

原始画作：assets/qingming-panorama-v1.png，2172×724，无标题、无截图裁切。
实现：atlas.js / style.css / index.html。既有动态街市保持为景点卡片上的二级入口。

四个景点范围以原图像素定义，图像、SVG 底稿层和按钮热点共享相同变换。镜头按容器与景点边界计算 contain 构图；介绍卡独占网格行。导航始终可切换景点。支持键盘聚焦、Enter、Escape、触摸导航及减少动态效果设置。

## 未完成的视觉素材

现有仓库没有对应本幅长卷的建筑透视底稿。people-ink.png 是人物精灵图，不是建筑底稿。当前不使用灰度、边缘检测或生成的异构图冒充成品。页面明确提示素材待补齐；hover 目前只呈现标签反馈，底稿层为空。

补齐方式：制作 2172×724 的完整、逐像素对齐的暖宣纸建筑底稿（屋脊、门窗、人物保持原位，细灰褐墨线与少量透视延长线），放入 assets。将 assets/atlas-draft.json 的 src 设为图片相对 URL。加载器校验实际尺寸；构图对齐仍须人工叠加检查。底稿按四个独立的 SVG 景点遮罩显示，纸墨边缘使用轻微位移，淡入 580ms / 淡出 420ms。素材缺失时不触发假线稿。

仍须在真实素材接入后验收：逐像素重合、整个景点的覆盖范围、580ms 揭示效果和交叉 hover 视觉衔接。当前框架完成不代表最终线稿视觉完成。
