# 古城烟火 V3.1 · 寻找与收藏

2026-10-07，本地可运行版本。入口 `explore.html`，保留 V2 的 320 位人物（318 个绘制实例）。

## 使用

构建：`npm run build`。预览：`python3 -m http.server 8768 --directory dist`，打开 `http://localhost:8768/explore.html`。

左下线索卡切换目标，不移动画卷；“给我提示”先给文字，再移动至大致范围。直接点击其他目标也能收集。右上收藏册显示进度，可筛选和回看；设置提供二次确认重置。键盘方向键移动画卷、加减号缩放，Enter 寻找画面中心人物；聚焦后 Tab 操作、Esc 返回。

## 实现

- `src/collection-data.js`：25 个真实目标、5 类各 5 个、15 个单人和 10 个群像。所有实体 ID 唯一分配，候选名称按现有动作调整。
- `src/collection.js`：线索、两级提示、图鉴、导览、完成总结、本地存档、透明轮廓命中、独立特写视口。先保存再展示；快速重复发现不重复计数。
- 展示和缩略图均由同一人物图集组成，群像保留世界坐标下的相对位置，不另行生成角色。高清出错保留进度，显示低清预览和重试按钮。
- 主画卷与特写各自维护缩放，返回保留画卷位置；响应窗口变化与减少动态效果。
- `src/explore-population.js`：依据用户关于人物拥挤的反馈，组内间距展开、人物尺寸调整为原来的 92%，先为群像保留空间再安置行人，迭代消除人物矩形重叠。桥面、田间、船上按局部锚点限制位移，题签区域排除。总人数和八区人数不变。
- 数据导出：`docs/people-v2/population.json`、`docs/people-v2/collection-targets-v31.json`。运行时仍以代码配置为准。
