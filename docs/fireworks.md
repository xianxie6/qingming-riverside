# 首页中秋烟花

2026-09-27 用户要求立即补放：增加北京时间 **9 月 27 日 08:24 至 23:59:59** 的补放时段，
当天 **22:00** 同样插播三轮感谢文字与 ChatGPT，9 月 28 日零点停止。其余效果、声音与节目顺序不变。
此版本同步发布 Cloudflare、GitHub Pages 和 Vercel。

原定时段为 **2026-09-25 20:00:00 至 23:59:59（北京时间）** 自动播放，
2026-09-26 00:00:00 停止。使用带 `+08:00` 的绝对时间，不随访客时区改变。
已经打开的页面会自动开始和停止；恢复后台页面时重新检查时间。
依赖设备系统时钟准确，无服务器授时依赖。

`atlas-fireworks.js` 是独立的透明 Canvas 2D 动画，包含升空、球面粒子绽放、
金柳、牡丹、菊花和双层花芯、重力与空气阻力、闪烁余烬及局部光晕。
`atlas-fireworks.css` 为播放时的天空增加渐变夜色，保留前景画卷和导航。
无新增第三方运行依赖、无外部 CDN 请求。

每一朵按大朵 / 特大朵交替，特大朵使用更多粒子与更大的展开半径。
穿插暖金、粉红、冰蓝、翡翠、淡紫的单色烟花和三色烟花，同一组大小与配色独立变化。

每次打开页面的开场，每实际炸开两朵烟花，粒子聚成一次祝福文字，共 **5 次**：
中文 → 英文 → 中文 → 英文 → 中文。
中文为「中秋快乐」「爱你们」，英文为「Happy Mid-Autumn Festival」「Love you all」。
手机英文分三行，避免长句超出屏幕。每次文字动画约 5.2 秒。

五次文字之后，每次升空轮流炸成 **玉兔 → 仙女**，共 **3 组 / 6 次造型**，
再回到五次中英文文字，循环至活动结束。中英文跨轮次继续交替，第二轮起文字为彩色。
玉兔轮廓来自街道的 `rabbit-lantern-v1.png`，去除木底座；仙女来自
`festival-dancers-v1.png` 的三种舞姿，轮换呈现并对衣袖与飘带做轻微舞动。
玉兔依次做摇耳、跃动和抬头望月动作；每次换一种颜色，轮换暖金、翡翠、粉红、
冰蓝、淡紫、银白，后续轮次也会改变朝向。每个造型约 6.8 秒，包含聚形、闪烁
停留和余烬散落。仍保留大小交替与多色爆闪。
暂停、后台恢复、调整窗口会保留轮次进度，刷新页面则从开场开始。

左右交替，大小与单色 / 多色继续变化；烟花绘制在文字下层并降低亮度。
每次绽放仍播放音效；伴随烟花不替换文字、不推进原祝福或玉兔仙女的轮次。
「ChatGPT」以中央大字与周围多组粒子字铺满天空，粒子上限为桌面 5200 / 手机 2600。
在 22:00 这一分钟打开或恢复页面也可以加入；同一页面只触发一次，22:01 后不补播。
暂停或调整窗口时只重新呈现未完成的当前一幕，不增加完整轮次。

用户提供的 `放烟花.mp3` 原样复制为 `assets/firework-bloom.mp3`（2.351 秒）。
每朵普通烟花、玉兔、仙女以及插播的每次文字绽放，都触发一次该录音。
普通祝福与同一次爆炸共用一次音效，避免重复叠响。
`firework-audio.js` 缓存解码后的录音，允许短暂重叠但最多 4 个声源。
用户提供的 `烟花背景.mp3` 原样复制为 `assets/firework-background.mp3`（约 27.17 秒），
作为首页全天循环背景音乐，不受烟花时间、暂停和活动结束影响；绽放音效叠加播放。
首页常驻「声音」按钮统一静音 / 开启两种声音。首次需要用户点击页面或按钮解锁
浏览器音频；不补放解锁前的爆炸声。静音后保持静音，直到再次主动开启。
暂停烟花或活动结束只停止绽放音效；离开首页、查看景点或切入后台同时暂停背景音乐，
返回首页后从原位置继续循环，避免与街道音乐叠加。

文字通过 Canvas 字形采样；造型由 `scripts/build-firework-shapes.py` 提取原素材的
透明边界和内部细节，生成 `atlas-firework-shapes.js`。首页仅加载约 100 KB 的坐标
而不额外下载 3.4 MB 原始图片，不展示图片贴纸。文字粒子上限为手机 1000 / 桌面 1800，
造型粒子上限为手机 1100 / 桌面 1800。

页面隐藏或进入动态街市后释放粒子并停止绘制，返回首页后按时段恢复。
手机减少粒子数量；像素比上限 1.5；粒子数量设上限并持续回收。
支持右上角暂停。系统设置减少动态效果时默认不自动播放，访客可主动开启。

## 本地预览

启动 `python3 preview.py --no-browser`，使用实际输出的端口访问：

`http://127.0.0.1:8765/index.html?fireworks=preview`

预览开关仅限 localhost / 127.0.0.1 / ::1，线上忽略该参数。
本地预览可额外添加 `&act=rabbit-1`、`rabbit-2`、`rabbit-3`、`colorful-text` 或 `sponsor`，
直接查看对应动作、返场彩色文字或 22:00 插播；这些跳转在线上无效。
正常地址不带参数，可用浏览器时钟模拟上述活动时段。

## 方案选择

调研了 [fireworks-js](https://github.com/crashmax-dev/fireworks-js) 和
[Firework Simulator v2 的中文版本](https://github.com/troyxun/fireworks-simulator)。
最终按本项目画卷布局自写动画，避免引入模拟器的独立界面和全屏黑背景。
没有复制上述项目代码。
GIF 的调色板与透明度限制不适合细腻的透明发光拖尾，长时间播放又会重复相同片段；
实时 Canvas 可以在小体积代码中持续产生变化，并处理响应式布局和准点启停。

验证：`node --test atlas-fireworks.test.cjs firework-audio.test.cjs`；完整项目检查：`npm test && npm run build`。
