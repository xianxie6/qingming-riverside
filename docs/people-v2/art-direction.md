# V2 素材制作说明

使用内置 image_gen 生成/编辑。下列为制作方向摘要，不是逐次工具调用的原文日志。

参考已有俯视地形画卷，保持米黄纸底、淡墨轮廓、低饱和赭石与灰绿、古代市井工笔绘画。人物服装和器具取古代日常生活风格，角色根据磨坊、茶市、虹桥、城门、码头、舟船、塔院、田地分别设置。每区八角色做成四列两行的透明图集，人物互不交叠，保持衣纹、手部、器具与动作可辨。具体角色和动作见 src/explore-population.js 的 roleActions。

清理原图旧人物后生成总底图；按 background-regions.json 所列范围裁取参考图，逐区重绘较清晰的建筑、石路、船舶与植被。网页叠加独立人物，保留原始 PNG，转换高低分辨率 WebP 供浏览器加载。
