## 已采用的优化

- 雨天地面湿润单独绘制。其最大纵坐标为 520，河水纹理采样区域从 522 开始；湿润变化不再让静态建筑缓存失效，也不再重复上传河水底图。雨、伞、湿润进程和河面动画保留。
- 14 张季节图从 PNG 改成无损、保留透明像素的 WebP。合计 35,817,169 → 24,522,932 字节，减少 31.5%；ImageMagick AE 比对全部为 0。原始 PNG 保留，并继续提供旧 URL，兼容已经打开的旧版页面。
- 粒子球体合并接缝和两端的重复顶点。每颗粒从 35 个顶点变为 20 个，36 个三角形、顶点位置与绕序、粒子数量、颜色、半径和全部动画保持。浏览器对 7 个确定时刻的聚散、悬停、鞠躬与离开状态逐像素对比，差异为 0。
- 行人 WebGL 网格复用顶点缓冲，只更新内容，不再每次绘制分配存储。
- 鼠标靠近、触屏按下或键盘聚焦穿越入口时，并行预加载依赖与原有素材；省流量模式不预加载。预加载图片的跨域凭据模式与 Three.js 一致。
- 庭院扫描框和数字完全透明后停止绘制、数字纹理更新；倒退时恢复。

## 实测

同一台 Apple M1 Pro，Chromium / ANGLE Metal，1440 × 1000，两个版本均由本地 HTTP 提供。进入虹桥、启动时雨，湿润值超过 0.07 后采样 3 秒。

| 指标 | 线上基线副本 | 优化包 |
| --- | ---: | ---: |
| rAF 帧数 | 80 | 142 |
| 约合 FPS | 27 | 47 |
| p95 帧间隔 | 50.1 ms | 33.4 ms |
| 背景重绘次数 | 80 | 0 |
| 采样末尾湿润值 | 0.234 | 0.234 |

单机短时测量不代表所有设备。粒子 GPU 微基准存在波动，不据此宣称整体帧率成倍提升；已舍弃未显示稳定收益的额外 GPU 计算缓存方案。
