# 古城烟火 V2 静态制作版

2026-10-07。依据《古城烟火-高密度人物画卷需求文档-V2》制作。当前不是完整 V2 验收交付。

## 预览

运行 `npm run build`，再运行 `python3 -m http.server 8766 --directory dist`，打开 http://localhost:8766/explore.html 。首页也有「古城烟火」入口。

## 已接入

- 八区共 320 位人物，318 个独立放置实例，其中两幅母亲图含幼儿。64 种绘制角色动作，52 组场景组合。人物重复使用角色素材，不代表 320 张独一无二的人物画。
- 水磨 40、茶市 65、虹桥 40、城门 60、码头 45、行舟 30、塔院 20、田畴 20。
- 独立透明人物图集、低/高清切换、八区局部背景、区域导航、鼠标和触控缩放、人物简述、可选环境声音。
- 主入口移除寻物任务及奖励界面。旧存档迁移只保留视角和声音。
- 人物配置在 `src/explore-population.js`；导出的完整元数据在 `docs/people-v2/population.json`。

## 检查记录

构建通过，183 个公开文件路径校验通过；全套 138 项代码测试通过，最后坐标调整后复跑 V2 两项测试通过。代码测试不等同美术验收。

`output/playwright/people-v2/` 保存八区各一张区域图、两张近景，以及全图与移动尺寸截图。桌面浏览器 1440×900、DPR 1，另用 390×844 窗口及模拟触控检查缩放。此前一次 2.5 秒合成滚轮操作采样约 60 FPS，帧间隔 P95 16.7ms；这是短时自动化浏览器测试，不代表真实手机表现。

## 尚未完成

- 约 24 组肢体/工具局部动作尚未制作，目前人物静态。
